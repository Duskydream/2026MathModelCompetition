# 第四问：双环覆盖与搜索定位联合调度

基线为2026-09-11拉取的origin/main，提交ffb79593e591cdb276234493b4cb93502e1b9177。优化前已将外层目录180个受跟踪文件同步并逐一SHA-256核对，旧文件备份于外层alignment_backup_20260911_144655。基线27项测试通过。证据见experiments/round4/main_alignment.json。

## 方法

搜索点由圆心、半径999米的内正12边形顶点、半径1800/cos(15°)米的外正12边形顶点组成；外环相对内环转15°，共25站。

外正12边形的内切圆半径1800米，因而包含目标圆。圆心与内环划分为12个三角形，内外环间划分为24个三角形。各边长不超过999米：外环边长为3600tan(15°)≈964.62米，内外相邻边长为sqrt(999²+(1800/cos15°)²−2×999×1800)，也小于1000米。任何源均在某个三角形内，与三个顶点的距离均小于1000米。源是顶点的凸组合，所以经过源的任意闭半平面至少含一个顶点。这证明了任意未知定向朝向下的连续覆盖，无需依赖采样网格推断。

已发现目标的轨迹跨搜索站保留。每步比较最近搜索站的距离与目标“第二测点加到定位中心”的估计路程，选择较小者。第二测点前向200米、侧向±100米，选择估计路程较短的一侧。方向观测构成角锥交，并与目标圆的48条外切半平面相交。第四问的no_signal不排除附近位置。near、最小包围圆认证和完整光学网格兜底沿用现有规则；只在清除16源或覆盖搜索与所有已发现目标均处理完后停止。
